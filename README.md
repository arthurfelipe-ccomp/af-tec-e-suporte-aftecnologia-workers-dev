# AF Tecnologia & Suporte

Landing page de apresentação dos serviços de TI da **AF Tecnologia & Suporte**, com atendimento em Dois Irmãos do Buriti - MS.

🔗 Site no ar: https://af-tec-e-suporte.aftecnologia.workers.dev/

Sobre o projeto

Página criada para apresentar os serviços e facilitar o contato dos clientes, que podem solicitar orçamento direto pelo WhatsApp.

Serviços apresentados

- Formatação e instalação de Windows
- Otimização de computadores
- Instalação de drivers
- Instalação do Office
- Manutenção de computadores

Recursos

- Layout responsivo (celular, tablet e computador)
- Botão de contato e orçamento via WhatsApp
- Metadados de SEO e dados estruturados para negócio local

Observação

Este repositório contém a versão compilada (build) do site, publicada na internet.
